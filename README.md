# FineVision
A software for vision tasks in Zhao lab
WIP！！！

# Installation
A conda environment with python = 3.10 is recommended. 
You need the following package: 
    pip install trodesnetwork zmq msgpack pyserial psychopy
Install the driver for QY eye tracker if you want to use it.

## Eye trackers

FineVision now has explicit QY and EyeLink task entry scripts backed by shared
experiment logic. See `EYELINK_INTEGRATION.md` for the project layout, custom
calibration workflow, EDF event alignment, and hardware setup checklist.
